# tauon

Music player


## Default keyboard shortcuts

Play/pause                              Space
Seek backward/forward in song           - / =
Previous/next track                     SHIFT + Left / Right
Locate playing track in playlist        '
Find in current playlist                CTRL + F  -or- \
Gloabal search                          Simply beging typing
Volume down/up                          CTRL + Down / Up
Show selected track info                CTRL + I
Showing playing track info              CTRL + P
Show artist info                        CTRL + O
Cycle through theme                     CTRL + [ / ]
Toggle console display                  `
Delete current playlist                 CTRL + W






## Configuration

Edit `input.txt` file in user data folder to redefine shortcuts.

To locate this file:  Menu > Settings > Open data folder

For Fractal Fedora 44: `~/.var/app/com.github.taiko2k.tauonmb/data/TauonMusicBox/`
